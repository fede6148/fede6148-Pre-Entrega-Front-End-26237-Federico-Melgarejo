# ZURIPANTIS

## Descripción

ZURIPANTIS es una página web de una tienda ficticia de ropa interior femenina.

El proyecto está desarrollado como una práctica de Frontend utilizando HTML y CSS, aplicando estructura semántica, diseño responsive y diferentes técnicas de organización de contenido.

La propuesta visual está inspirada en un estilo pop-art/comic, utilizando colores llamativos, bordes definidos y una estética moderna y juvenil.

## Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts
- Formspree
